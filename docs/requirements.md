# 요구사항: 건강보험 청구 대시보드

인터뷰 일자 2026-10-21 · 요청자: 식약처 보건의료분석담당자

## 사용자와 목적
- 보는 사람: 담당자 본인(분석) + 내부 보고(화면·캡처)
- 배경: 병원별 진료비가 많이 차이난다는 이야기가 있어 주기적으로 확인하고 싶음
- 답해야 할 질문
  1. 호흡기 질환 진료비는 기관 종별로 얼마나 차이 나는가?
  2. 그 차이는 같은 상병끼리 비교해도 남는가? (환자 구성 차이 배제)
  3. 월별로 추이가 변하는가? (계절성, 최근 변화)

## 범위 (인터뷰 결정)
| 항목 | 결정 |
|---|---|
| 분석 대상 | 주상병(`claim.main_sick`)이 호흡기 J코드(J00~J99) 전체, 약 13,285건 |
| 비교 단위 | 기관 **종별**(`institution.cl_cd`) — 개별 기관 비교는 이번 범위 밖 |
| 진료비 지표 | 명세서(건)당 총진료비(`rvd_rpe_tamt_amt`) |
| 보정 | 같은 상병끼리 비교(상병별로 종별 비교). 연령·성별 보정은 하지 않음 |
| 편차 표현 | 분포: P25 / P50 / P75 / P90 (박스플롯) |
| 갱신 주기 | 월 1회 (`python3 build.py --refresh`) |
| 기간 | 2024-01 ~ 2025-12 (24개월) |
| 필터 | 지정 없음 → 기본값으로 기간(월), 상병, 종별 (아래 가정 참고) |

## 지표 목록
이름은 `build.py`의 `metric_<이름>` = `data/<이름>.json` = `<section data-metric>` 과 동일.

| 이름 | 정의 | 필요한 테이블 | 차트 |
|---|---|---|---|
| kpi_summary | 호흡기 명세서 수, 총진료비, 건당 평균·중앙값·P90, 종별 간 중앙값 최대/최소 배율 | claim | 숫자 카드 |
| monthly_trend | 월별 호흡기 명세서 수와 건당 진료비(P50, P90) | claim | 선 차트 |
| cost_by_class | 종별 건당 진료비 분포 (P25/P50/P75/P90, 건수) | claim, institution, code_table | 박스플롯 |
| cost_by_class_sick | 상위 상병 × 종별 건당 진료비 분포 (같은 상병끼리 비교) | claim, institution, code_table, sick_master | 상병 선택 + 박스플롯 / 히트맵 |
| sick_mix | 호흡기 상병별 건수·비중·종별 구성 | claim, sick_master | 막대 |

## 가정 (확인 필요)
- 종별 코드명(`cl_cd` 31/11/21/01)은 `code_table`의 종별코드로 해석한다.
- 입원(`fom_tp_cd`=021, 호흡기 53건)은 표본이 작아 기본은 외래만 비교하고, 입원 포함 여부는 토글로 둔다.
- 종별·상병 칸의 표본이 30건 미만이면 분포를 표시하지 않고 "표본 부족"으로 표시한다.
- 화면: 한 페이지 스크롤, 맨 위 KPI → 월별 추이 → 종별 분포 → 상병별 비교 순. 모바일은 우선순위 낮음.

## 데이터 한계
- 기관명이 없어(`institution`은 ID·종별·권역만) 특정 병원 식별은 불가. 이번 범위도 종별 비교.
- 법정감염병 급수가 붙은 호흡기 상병은 계절성 인플루엔자(J101, 409건)뿐이라 감염병 별도 분석은 제한적.
- 환자 3,000명 규모 표본. 진료비는 청구액 기준이며 실제 비급여는 포함되지 않음.
- `patient.prem_quintile` 등 일부 NULL 있음(이번 지표에는 미사용).
